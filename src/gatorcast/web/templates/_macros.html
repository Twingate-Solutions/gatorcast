{# Shared presentation macros for the kubectl activity page, the unified Search page (_rows.html / _results.html), and later the dashboard feed. Import with `{% from "_macros.html" import ... %}` (macros are pure: they use only their arguments, so no `with context` is needed). Safety rules, unchanged from activity.html: * Every value is autoescaped. Never add |safe. Stored request URLs and usernames are attacker-influenced. * Never interpolate stored text into a class name. The status band is computed from the integer status code, "failed" is matched by equality, and severity and session status go through sev_cls / status_cls below, which map a closed set of keys to fixed class names (anything else gets a neutral class). * Stored text shown inline (usernames, system addresses, URLs, shell users, gwops app names) is wrapped in or carries a class that app.css gives `unicode-bidi: isolate`, so a bidi override inside the value cannot reorder neighbouring text. Visual language (see app.css, "kubectl activity"): * HTTP status -> small monospace chip; 4xx/5xx are amber (--warn). * failed outcome -> red (--err) pill with a cross glyph plus a red stripe on the row. This is the Gateway's "API request failed" outcome and is deliberately different from any non-2xx status: a 502 that the Gateway logged as completed gets only the amber chip. #} {# Fixed-map class lookups.
